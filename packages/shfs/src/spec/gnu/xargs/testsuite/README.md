# GNU findutils xargs fixtures

These fixture files are copied from the GNU findutils DejaGNU xargs test
suite in:

`opensrc/repos/github.com/jamesyoungman/findutils/xargs/testsuite/`

Only the files needed by the selected SHFS xargs spec cases are copied here.
The `.exp`, `.xi`, `.xo`, and `.xe` fixture contents are kept verbatim so the
ported tests remain anchored to the original GNU source artifacts.
